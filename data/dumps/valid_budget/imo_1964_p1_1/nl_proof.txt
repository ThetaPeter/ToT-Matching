We work throughout with a fixed natural number \(n\). First note that \(2^3\equiv 1\pmod{7}\). It follows that the multiplicative order of \(2\) modulo \(7\) is exactly \(3\). A standard property of orders then yields that \(2^n\equiv 1\pmod{7}\) if and only if this order divides \(n\), i.e., if and only if \(3\mid n\). Equivalently, \(7\) divides \(2^n-1\) if and only if \(2^n\equiv 1\pmod{7}\). Combining the two biconditionals therefore gives that \(7\) divides \(2^n-1\) if and only if \(3\mid n\). In particular the forward implication holds, which is the required statement.
