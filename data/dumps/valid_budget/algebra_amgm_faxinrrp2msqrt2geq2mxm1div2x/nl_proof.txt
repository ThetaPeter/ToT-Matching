Assume \(x>0\). By the AM-GM inequality,
\[
x+\frac1{2x}\ge 2\sqrt{x\cdot\frac1{2x}}=\sqrt2,
\]
with equality if and only if \(x=1/\sqrt2\). Rearranging immediately yields
\[
2-\sqrt2\ge 2-x-\frac1{2x}
\]
for every \(x>0\), with equality if and only if \(x=1/\sqrt2\). In particular the constant \(2-\sqrt2\) is attained, so the bound is sharp.

Thus
\[
2-\sqrt2\ge 2-x-\frac1{2x}\qquad\text{for all }x>0,
\]
with equality if and only if \(x=1/\sqrt2\).
